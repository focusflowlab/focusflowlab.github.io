How to use it

A focus block is a set stretch of time where you do one thing: no phone, no switching tabs, no “quick check”. Short blocks with breaks are easier to start than a vague evening of studying.

  • Start with 25 minutes if focusing is hard right now. Move up to 45 or 50 as it gets easier.
  • End each block with a self-test. Writing down what you just learned, without looking, shows what actually went in.
  • Take the break. Stand up, get water, look at something far away. Skipping breaks makes the next block worse.

The Exam Sprint Planner uses four of these blocks a day.

Questions people ask

Is 25 minutes the right length?

It’s a good place to start. Many people settle on 45 or 50 minutes once focusing gets easier. Pick the longest block you can keep without checking your phone.

Does the timer keep running in the background?

Yes. It counts from the clock, so it stays right if you switch tabs. Keep this tab open.

Does it save anything?

Only the count of blocks you finish today, in this browser.
